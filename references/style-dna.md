# 冷檬风格 DNA

## 一句话

柔和、治愈、水彩、暖黄、留白、干净、有故事感。像一个会画画的小姑娘，在水彩纸上认认真真把一件事画给你看。

不是黑白怪诞线稿，不是商业矢量插画，而是温暖通透的水彩小场景。

## 必须

- 画幅由用户选定（见 SKILL.md 第一步），不固定 16:9。
- 干净浅底色：奶油白、米白或极浅的暖黄，带一点水彩纸的通透感，但不要明显纸纹、不要做旧、不要脏。
- 柔和水彩手绘：颜色有水痕晕染、边缘柔和，不要锐利矢量平涂、不要粗黑描边。
- 大量留白：主体占画面约 40%-60%，至少 35% 安静留白，最好有一整块干净区域。
- 少量中文手写标注：最多 4-6 处，每处 2-8 个字，字体像柔和的手写体。
- 一张图只讲一个核心动作、结构、状态或隐喻。
- 结构自然表达，不要在图上写结构类型名称。
- 冷檬必须在画面里做一件具体的事，不是站桩。

## 配色

- 主色：明黄/暖黄（冷檬的连衣裙、重点物件、画面情绪色）。
- 发色：浅金/奶茶金，柔和不刺眼。
- 点缀：柔粉（腮红、小花）、薄荷绿或浅天蓝（小物件、次要元素）。
- 底色：奶油白、米白。
- 标注文字：暖棕或深灰，不要纯黑大块字。
- 颜色要通透、克制、柔和，宁可淡不要浓。不要高饱和撞色，不要荧光色。

## 绝对不要

- 不要 PPT 信息图、正式流程图、课程课件。
- 不要商业矢量插画、扁平风 UI 图标、科技感界面。
- 不要浓重阴影、强烈透视、3D 渲染感。
- 不要复杂背景：城市、风景、房间、杂物堆满画面。
- 不要把冷檬画成真人、画成成人、画成写实动漫。
- 不要给冷檬换衣服、换发色、换发型（严格按 IP 设定）。
- 不要大段中文说明文字。
- 不要左上角写"流程图/系统架构图/常见坑/路线图"等类型标题。
- 不要恐怖、暗黑、搞怪丑化的方向。

## 审美方向

要治愈、温柔、有好奇心、有点小忙碌、像一个热心又认真的小姑娘在帮你把事情理顺。
不要幼稚低龄、不要过度甜腻、不要死板、不要冷冰冰的工业感。
