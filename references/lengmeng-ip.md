# 冷檬 IP

## 角色定义

冷檬是冷檬配图的固定视觉 IP。她不是吉祥物贴纸，也不是站在角落卖萌的摆件，而是正在认认真真参与这件事的小主人公——像一个热心、细心、有点小忙碌的小姑娘，亲手帮你把抽象的事情画成一个能看懂的小场景。

## 外形（严格遵守）

- Q 版 chibi 小女孩，约 2.5 头身，头大身小。
- 头发：浅金/奶茶金色，双丸子头——两侧各一个蓬松圆发髻，发髻旁别着一朵（或一对）明黄色五瓣小花发饰；额前有刘海，鬓角有自然散落的软发。
- 眼睛：又大又圆的蓝灰色/灰蓝色眼睛，长睫毛，眼神温柔好奇。
- 脸：圆圆的娃娃脸，粉扑扑的腮红，小嘴巴，表情认真而略带专注。
- 服装：明黄色泡泡袖连衣裙，白色蕾丝荷叶边娃娃领、袖口荷叶边、裙摆多层白色蕾丝。
- 袜子：白色蕾丝边短袜。
- 鞋子：黑色亮面玛丽珍小皮鞋。
- 画风：柔和水彩，颜色通透，边缘带轻微水痕。

可对照 `assets/coldmeng-character-ref.jpg` 校准外形。

## 性格

- 热心、细心、认真、有点小紧张地想把事情做好。
- 好奇心强，遇到新东西会歪头看。
- 不卖惨、不搞怪、不过度眨眼比心。
- 像在帮你整理书架、给花浇水、递一封信、把东西归类。
- 软萌但有行动力。

## 常见职责

让冷檬承担核心动作，而不是站旁边看：

- 捧着、递着、抱着一叠纸/一本书/一个小盒子。
- 用小梯子爬上爬下取东西。
- 给小树苗/小花浇水。
- 把散落的物件分门别类放进小抽屉/小篮子。
- 推开一扇小门、拉开小抽屉、拧开水龙头。
- 举着一盏小灯/放大镜在看东西。
- 牵着一根线、推着小推车、端着小托盘。
- 在小黑板/小纸条上写字、贴标签。
- 踮脚够高处的东西、坐在小凳子上专注做事。
- 把一个东西拆成几份、或把几份收成一个。

## 禁止

- 不要让冷檬只是站在画面角落摆 pose。
- 不要改变发型、发色、服装颜色。
- 不要画成真人比例、不要画成性感成熟形象。
- 不要夸张表情包式脸（斗鸡眼、吐舌、过度大哭大笑）。
- 不要给她多余的道具堆砌（手里同时拿十样东西）。
- 不要让她抢掉结构表达——她在做事，不是在表演。

## 判断标准

如果去掉冷檬，这张图就只是一张空场景或几个无关联物件，说明她太装饰了；要重写提示词，让她手里正在做的那件事就是这张图要讲的核心动作。
