# 冷檬配图（lengmeng-illustrations）
> 把中文文章里的判断、流程、状态和隐喻，变成一张张水彩、暖黄、治愈又好懂的正文配图。
>
> 先问画幅再动笔 | 冷檬 IP | 奶油白水彩 | 少量暖棕手写中文标注 | Agent Skill

---

## 这个仓库是什么

lengmeng-illustrations 是一个给 AI Agent 用的配图 Skill，用来指导它为中文文章、公众号、小红书、博客和方法论内容生成正文配图。

它不是一套通用插画 prompt，也不是 PPT 信息图模板。它要做的事是：先读懂文章里哪里是认知锚点，再把其中一个判断、流程、结构、状态或隐喻，变成一张有温度、有故事感、读者一眼能懂的水彩小图。

固定视觉 IP 叫「冷檬」：一个浅金双丸子头、穿黄色蕾丝连衣裙的 Q 版小女孩。她不是摆在角落的吉祥物贴纸，而是正在画面里亲手做事的小主人公——浇水、分类、推门、贴标签，把抽象的事情做给你看。

一句话：**让 AI 不只是「配一张好看的图」，而是把文章里那一下认知转折，画成冷檬正在做的一件小事。**

---

## 适合谁用

特别适合：

- 写中文文章、公众号、小红书，需要正文配图的人
- 做知识型、方法论、个人成长类内容，想让画面有温度而不是冷冰冰流程图的人
- 希望一套 IP 形象稳定复用、不每张图都换风格的人
- 想要「软萌但不幼稚、治愈但不甜腻」视觉语言的人
- 用 AI Agent 做内容生产，想把配图流程固化下来的人

不适合：

- 想要商业插画、品牌 KV、精致扁平矢量图的人
- 想要正式 PPT、架构图、工程流程图的人
- 想要黑白线稿、怪诞极简风（那是隔壁小黑的路数）的人
- 想把大段正文、长段解释塞进一张图的人
- 需要可编辑 SVG / Figma 源文件的人

---

## 它会产出什么

默认输出：

- 用户选定画幅的正文配图（16:9 / 1:1 / 3:4 / 4:5 / 9:16 / 自定义均可）
- 一篇文章的 3-6 张 shot list
- 每张图的主题、核心意思、结构类型、冷檬在做什么、建议中文标注
- 最终 PNG，保存到 `assets/<article-slug>-illustrations/`

默认不输出：

- PPTX / PDF / Keynote
- SVG / HTML 可编辑图
- 商业海报、封面 KV、表情包套图
- 大段文字型信息图

---

## 视觉风格

这个 skill 默认使用冷檬的「水彩暖黄治愈」风格：

- 奶油白 / 浅米白底，不要做旧纸纹、浓重阴影、脏灰
- 柔和水彩晕染，颜色通透，边缘带水痕，不要锐利矢量平涂、不要粗黑描边
- 大量留白，主体只占画面约 40%-60%
- 明黄主色（冷檬的连衣裙）+ 柔粉 / 薄荷 / 浅蓝小点缀
- 少量暖棕色手写中文标注，每处 2-8 个字
- 一张图只讲一个核心动作、结构、状态或隐喻
- 冷檬必须承担核心动作，不能只是站在旁边卖萌
- 治愈、温柔、有故事感，但不幼稚、不甜腻

## 示例效果

> 示例图会随实际使用积累。冷檬的每张图都应让读者先觉得「好温柔」，再 1 秒看懂在讲什么。

首批样例待补充：通常一篇文章会产出 3-6 张，分别对应核心判断、前后对比、流程闭环、角色状态等不同结构类型。

```bash
git clone https://github.com/1162711644/lengmeng-illustrations.git
```

把整个目录放到你的 skills 加载目录下（以豆包 / Doubao 工作区为例）：

## 怎么用

### 第一步永远是：先选画幅

冷檬和其他配图 skill 最大的不同——它不会一上来就画图。发文案后，它会先问你要哪种画幅：

1. 16:9 横版（公众号头图 / Banner）
2. 1:1 方图（小红书主图）
3. 3:4 竖版（小红书竖图）
4. 9:16 竖版（手机全屏 / 短视频封面）
5. 其他（自定义比例或像素）

### 只做配图规划，不生图

```text
用冷檬配图 skill，先不要生图。
请分析下面这篇文案哪里值得配图，先告诉我画幅建议，再给 3-5 张 shot list。
每张图写清：放哪段后、主题、核心意思、结构类型、冷檬在做什么、建议中文标注。
<粘贴文案>
```

### 直接生成正文配图

```text
用冷檬配图 skill，画幅选 3:4 竖版，把下面这篇文案生成 4 张正文配图。
要求：奶油白水彩底、冷檬穿黄色蕾丝裙、大量留白、少量暖棕手写标注。
<粘贴文案>
```

### 为单个概念出一张图

```text
用冷檬配图 skill，画幅 16:9，为「焦虑不是因为事多，而是因为每件事都开了个头却没收尾」画一张图。
冷檬要在画面里做一件具体的事来表达这个意思。
```

### 修正图里的问题

```text
用冷檬配图 skill 帮我编辑这张图：去掉左上角的标题文字，冷檬的发型和服装保持原样，其他都不要动。
```

## 工作流程

这个 skill 的流程是：

1. **先问画幅**：用户答复尺寸前，不调生图工具
2. 读文案 / 链接 / Markdown / 截图，提炼核心观点和认知转折
3. 出 shot list：每张图只选一个认知锚点，默认 3-6 张
4. 为每张图选结构类型：流程闭环 / 前后对比 / 角色状态 / 概念隐喻 / 方法分层 / 路径地图 / 小场景叙事
5. 重新发明一个温柔但成立的隐喻（小书架、花盆、小梯子、小推车……）
6. 让冷檬亲手做这件事，而不是站在旁边
7. 按选定画幅换算宽高，每张图单独调用图像模型生成
8. 按 QA 清单检查：水彩感、冷檬形象、留白、中文标注、非 PPT 感
9. 保存 PNG，报告每张图的用途和路径

## 注意事项

- 图里的中文越短越稳定，每处标注控制在 2-8 个字。
- 每张图只讲一个核心结构，不要把文章做成说明书。
- 冷檬必须承担核心动作；如果去掉冷檬画面仍然完全成立，说明她太装饰了。
- 冷檬的发型、发色、黄色连衣裙不要让模型自由发挥，提示词里要钉死。
- AI 生图偶尔出现错字、多余标题、形象走样，生成后必须按 QA 清单过一遍。
- 错字严重时优先减少标注数量重生成，而不是硬修。
- 不要为了萌让冷檬眨眼、比心、摆 pose；让她专注做事。
